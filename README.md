# 코인어카운트

코인어카운트는 Backpack·업비트·빗썸 거래 자료를 PC 안에서 정리하는 로컬 원장 및 증빙 보고서 도구입니다. 거래내역 가져오기, 거래소별 취득가액 원장, 자산별 손익, 기간별 보고서 미리보기와 Excel 추출을 제공합니다.

> 이 프로그램의 계산 결과는 세무 신고를 보조하기 위한 자료입니다. 최종 신고 기준과 판단은 세무 전문가에게 확인하세요.

## 전체 제품 실행

이 저장소는 자료 업로드·수정·저장·보고서 추출 기능이 활성화된 전체 제품 소스입니다.
`start_tax_tool.cmd`를 실행하면 빈 장부로 시작하며, 사용자가 가져온 자료는 자기 PC의 `data` 폴더에 저장됩니다.
파일을 직접 가져오는 기본 기능에는 거래소 API 키가 필요하지 않습니다.

현재 제품은 개인 PC에서 사용하는 구조입니다. 여러 사용자가 인터넷에서 각자의 장부를 사용하는 서비스로 운영하려면 사용자 로그인, 사용자별 데이터 접근 제어, 영구 DB·증빙 저장소를 추가해야 합니다.

## GitHub 업로드

새 `coinaccount` 저장소에 이 폴더 안의 파일과 `src`, `tests` 폴더를 올리세요.
원본 거래자료, 실제 `.env`, API 키는 포함되어 있지 않습니다.
GitHub에서 내려받은 사용자는 Python 3.11 이상을 설치한 뒤 `start_tax_tool.cmd`로 실행할 수 있습니다.

## 새 Windows PC에서 실행

필요한 것은 Windows 10/11, Python 3.11 이상, 최초 설치 시 인터넷 연결입니다.

1. 전달받은 ZIP을 원하는 폴더에 압축 해제합니다.
2. Python이 없다면 [Python 공식 사이트](https://www.python.org/downloads/windows/)에서 설치하고 `Add Python to PATH`를 선택합니다.
3. `start_tax_tool.cmd`를 더블클릭합니다.
4. 최초 실행에는 전용 가상환경과 필수 패키지가 자동 설치됩니다.
5. 설치 후 브라우저에서 `http://127.0.0.1:8765`가 자동으로 열립니다.

자동 설치가 실패하면 `setup_tax_tool.cmd`를 먼저 실행한 뒤 오류 메시지를 확인하세요. 프로그램 종료는 실행 중인 명령창에서 `Ctrl+C`를 누르면 됩니다.

## 개인정보 없이 다른 사람에게 공유

`make_share_package.cmd`를 더블클릭하면 `dist` 폴더에 날짜가 붙은 공유용 ZIP이 만들어집니다. 이 ZIP에는 다음 항목이 들어가지 않습니다.

- `.env`와 API 키
- `.venv` 개발 환경
- `data` 폴더의 SQLite 원장
- 업로드한 PDF·CSV 및 휴지통 자료
- 내려받거나 직접 등록한 자산 로고

따라서 일반적인 제품 공유에는 생성된 ZIP만 전달하면 됩니다. ZIP을 만들기 전에 실제 거래자료를 수동으로 프로젝트 소스 폴더에 넣지 마세요.

## 내 기존 원장을 다른 PC로 이전

이 작업은 제품 공유와 다릅니다. 양쪽 PC에서 코인어카운트를 완전히 종료한 뒤 기존 PC의 `data` 폴더 전체를 새 PC의 코인어카운트 폴더에 복사합니다. 새 PC에 이미 데이터가 있다면 먼저 별도 백업을 만드세요.

`data`에는 거래내역과 원본 증빙이 포함될 수 있으므로 본인 소유 PC 사이에서만 암호화된 저장장치나 신뢰할 수 있는 전송 수단을 사용하세요. `.env`가 필요하다면 별도로 안전하게 옮기고 타인에게 전달하지 마세요.

## 백업

프로그램을 종료한 상태에서 `data` 폴더 전체를 복사하면 원장, 보관 원본, 휴지통 및 자산 로고를 함께 백업할 수 있습니다. 일부 파일만 복사하면 DB와 증빙 파일의 연결이 맞지 않을 수 있습니다.

## 검토 센터의 묶음 처리

검토 센터의 `입출금·지갑 이동 검토` 카드에서 `묶어서 검토`를 누르면 거래소 간 이동 후보와 주소별 거래 묶음을 볼 수 있습니다. 이동 후보는 같은 자산, 출금 후 30분 이내, 기록된 수수료 또는 0.1% 이하의 수량 차이를 기준으로 서로 겹치지 않는 쌍만 제안합니다. 후보가 실제 본인 계정 간 이동인지 확인한 뒤 선택해서 저장하세요.

주소별 묶음에서는 같은 개인 지갑과 오간 거래를 선택하고 지갑을 한 번 지정해 저장할 수 있습니다. 원본 주소만으로 소유권을 추정하지 않으며, 주소가 없는 기록은 거래소·자산·입출금 유형별로 모읍니다. 기존 원가가 없거나 통화 간 가격 증빙이 부족하면 이동을 저장해도 취득가 미확인 상태가 남습니다. 묶음 저장은 거래별 이력을 남기고, 오류가 발생하면 선택한 거래 전체를 되돌립니다.

## 검토센터의 과거 가격

`거래시점 가격 채우기`는 원 거래소의 1분봉을 먼저 조회합니다. 해당 마켓의 과거 분봉이 없으면 CoinGecko의 인접 과거 시세를 대체 증빙으로 사용하며, 국내 거래소는 KRW 평가액, Backpack은 USD 평가액으로 저장합니다. 대체 시세는 원 거래소 분봉보다 낮은 `MEDIUM` 신뢰도로 표시됩니다.

CoinGecko 공개 API도 사용할 수 있지만 호출 제한이 있습니다. 반복적으로 호출 제한이 나오면 CoinGecko Demo API 키를 발급받아 `.env`의 `COINGECKO_API_KEY`에 넣을 수 있습니다. 유료 Pro 키는 `COINGECKO_PRO_API_KEY`에 넣습니다. CoinGecko에 가격 이력이 없거나 티커가 모호한 자산은 임의 추정하지 않고 가격 미확인으로 남깁니다.

Backpack 입금 자료의 `Source`가 `Internal`이면 에어드랍으로 자동 분류됩니다. 에어드랍은 일반 내부이동과 연결하거나 일괄 승인하지 않으며, 조회된 가격을 승인하거나 검토센터에서 자산 1개당 USD 취득가를 직접 입력해야 합니다. 승인된 총 취득가는 수령 시점의 보유 로트에 추가되어 이후 매도의 이동평균 PNL에 반영됩니다. 국내 거래소의 수동 가격은 KRW, Backpack은 USD로 저장되고 입력 이력과 메모가 보존됩니다.

## 다른 개발자나 AI 모델에게 전달할 때

공유용 ZIP과 함께 원하는 변경사항을 설명하면 됩니다. 개발 환경 설치는 다음 명령으로도 가능합니다.

```powershell
.\setup_tax_tool.cmd
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\start_tax_tool.cmd
```

주요 구성은 다음과 같습니다.

- `src/backpack_tax/`: 웹 앱, 거래자료 해석, 원장·손익·Excel 처리
- `src/backpack_tax/templates/`: 화면 템플릿
- `src/backpack_tax/static/`: CSS와 제품 로고
- `tests/`: 자동 테스트
- `data/`: 사용자 로컬 데이터(공유 ZIP 및 Git 제외)

다른 개발자는 기능을 수정한 뒤 전체 테스트를 통과시키고, 실제 개인정보나 거래 원본을 테스트 자료로 추가하지 않아야 합니다.

## 보안 원칙

- 웹 서버는 이 PC에서만 접근 가능한 `127.0.0.1`에 열립니다.
- 원본 PDF·CSV, SQLite DB와 비식별 증빙은 `data` 아래에 저장됩니다.
- 업비트 PDF 비밀번호는 문서를 여는 동안만 사용하고 저장하지 않습니다.
- 빗썸 개인정보·계좌정보는 원본 대신 비식별 처리한 증빙만 보관합니다.
- `.env`, `data`, `imports`, 가상환경과 빌드 결과는 Git 제외 대상으로 설정되어 있습니다.
